# 前缀KV与CUDA Graph形式化验证

9项安全性质均为UNSAT，9项故障负控制均为SAT；另有18项前提可满足性检查通过。每项SMT2、前提SMT2和具体反例均保存。

| 性质 | 证明对象 | 安全查询 | 负控制 |
| --- | --- | --- | --- |
| P1-key | 缓存身份覆盖前缀状态的全部上下文 | UNSAT | SAT |
| P2-causality | 因果依赖逐层保持前缀不依赖后续问题 | UNSAT | SAT |
| P3-isolation | 工作区重置及后续请求不改写持久前缀 | UNSAT | SAT |
| P4-restore | 28层K/V恢复准确且游标回到前缀边界 | UNSAT | SAT |
| G1-capacity | 真实准入守卫保证最多63步decode写入不越界 | UNSAT | SAT |
| G2-mask | 单步写入后mask恰好覆盖有效KV，不暴露未来槽位 | UNSAT | SAT |
| G3-replay | 固定绑定下图数据流重放与eager单步迁移相同 | UNSAT | SAT |
| G4-addresses | 恢复与解码保持全部KV、游标及输入缓冲地址 | UNSAT | SAT |
| G5-rollback | 预热和图捕获后恢复有效KV、首token与游标 | UNSAT | SAT |

求解器z3-solver 5.4.1.0，Transformers 5.17.0。原型runtime SHA256为`3e84b00485ea92db7f1b8d6abb64be1ea6765a19ec1a4e76f75e14bca70f10f1`。

验证直接抽取并执行Runtime的_save、_restore、_decode、build_graph及已安装StaticLayer.update、CacheLayerMixin.reset，在符号张量语义下构造状态迁移。P2是任意前缀长度／任意满足前提的语言层的因果依赖归纳步；28层通过归纳应用。所有28层存储在P3/P4和G类迁移中展开。单个KV标量代表任意头／通道的元素，复制与索引操作对这些元素逐坐标成立。

G3把实际_decode生成的符号张量数据流保存为捕获图，再用当前绑定缓冲的值代入；与重新执行源码得到的eager迁移比较。负控制冻结捕获时游标和delta，能够找到不同长度请求使用旧位置的反例。G5执行真实建图控制流；成功prefill、流顺序和CUDA捕获语义是接口前提。

形式化结论覆盖前缀身份、因果依赖、所有权隔离、恢复、静态容量、mask、地址和图数据流迁移。SHA256无碰撞、PyTorch张量算子及CUDA Graph按接口执行属于可信前提；神经网络数值以确定性未解释函数表示，不据此证明BF16逐位等价或GPU驱动／kernel正确。已有GPU状态检查、真实答案和ANLS门槛补充验证具体设备执行。

## 复现

从仓库根目录执行`./stage_2/experiments/cross_layer_v2/run.sh formal`重放全部36份SMT2。重新建模使用同一入口的`--output 新目录`，不覆盖已保存证据。无需GPU、模型权重、网络或额外求解服务。环境复用stage_2/.venv中的z3-solver==5.4.1.0；输出含版本、源码哈希和快照。
